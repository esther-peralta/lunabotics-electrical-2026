# lunabotics-electrical-2026
This repository contains the electrical hardware documentation, embedded
software, research, and assignments for the Temple Robotics Lunabotics team.

## Meeting Information

- Day: Monday
- Time: 6:00 PM
- Location: IDEAS Hub

## Electrical Team Responsibilities

The electrical team is responsible for:

- Sensor selection and integration
- Motor drivers and motor control
- Power distribution
- Fuse selection
- Emergency-stop integration
- Current and temperature monitoring
- Wiring diagrams
- Electrical testing and documentation

## Repository Structure

- `firmware/` – Arduino and microcontroller programs
- `hardware/` – Component lists, wiring information, and schematics
- `docs/` – Meeting notes and technical research
- `assignments/` – Member assignments and instructions

## Team Workflow

1. Pull the newest version of `main`.
2. Create a new branch.
3. Make and test your changes.
4. Commit the changes.
5. Push the branch to GitHub.
6. Open a pull request.
